# 设计决策：敏感信息脱敏（redact D1）

## 背景

日志/审计场景不能泄露完整凭证（口令、API Key、Token）。

## 决策

1. **通用掩码** `Mask(s, head, tail)`：保留前 `head` 与后 `tail` 个字符，中间以 `*` 打码（按字符而非字节，中文安全）；负数按 0 处理
2. **短值整体打码**：长度不足以同时保留首尾时，整体替换为 `****`——不泄露前缀与长度信息
3. **凭证类默认** `MaskToken`：首 4 尾 4（对齐常见 API 平台展示惯例）
4. **纯函数、无 IO**：脱敏规则演进（如需按凭证类型差异化）由 fixtures 驱动

## 待定

- 按凭证类型（password/api_key/token）差异化脱敏规则是否必要
